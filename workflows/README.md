# Workflows 目录

## 概述

这个目录包含实验性的多Agent协作工作流脚本。

## 文件说明

### pattern5_fix.js
**状态**: 实验性，未成功运行  
**目的**: 尝试自动化 Pattern 5 的完整修复流程

这是一个6阶段的多Agent协作工作流：
1. 分析器 - 理解问题
2. 实现者 - 编写代码
3. 审查者 - 代码审查
4. 测试者 - 运行测试
5. 提交者 - 创建PR
6. 监控者 - 监控CI并处理失败

**结果**: 工作流启动但未成功运行

**经验教训**:
- 复杂度过高
- Agent间协调困难
- 简单的增量式手动修复更可靠

### pattern5_test.js
**状态**: 测试工作流  
**目的**: 验证工作流基础功能

简单的测试工作流，用于验证 Agent 调用是否正常。

## 设计文档

详细的工作流设计说明参见: `docs/fix-reports/PATTERN5_WORKFLOW_DESIGN.md`

## 使用方法

```javascript
// 运行工作流
Workflow({
  scriptPath: '/path/to/workflow.js'
})

// 查看进度
/workflows
```

## 未来改进

1. **简化设计**
   - 单阶段工作流而非多阶段
   - 减少Agent间依赖

2. **增加容错**
   - 更好的错误处理
   - 支持断点恢复

3. **分步执行**
   - 不要一次性运行所有阶段
   - 每个阶段可独立验证

## 注意事项

这些工作流是实验性的，不建议用于生产环境。对于实际的修复工作，建议使用传统的增量式方法：
1. 阅读测试理解问题
2. 定位和修改代码
3. 运行测试验证
4. 提交代码
