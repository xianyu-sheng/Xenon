### 2. 核心特性

✅ **智能回退机制**
```
用户输入 → 正则分类器 → 成功? → 返回意图
                    ↓ 失败
                LLM 分类器 → 成功? → 返回意图
                        ↓ 失败
                    返回 None
```

✅ **置信度过滤**
- 置信度 ≥ 0.7：接受分类结果
- 置信度 < 0.7：返回 None，避免误判

✅ **优雅降级**
- LLM API 失败 → 静默降级，返回 None
- 不影响主流程，不抛出异常

✅ **完全可配置**
```yaml
intent_classifier:
  enabled: true  # 启用/禁用
  model: "deepseek/deepseek-v4-flash"  # 模型选择
  confidence_threshold: 0.7  # 置信度阈值
  timeout: 5.0  # 超时设置
```

## 🚀 使用方式

### 启用分类器

编辑 `~/.xenon/config.yaml`：

```yaml
intent_classifier:
  enabled: true
  model: "deepseek/deepseek-v4-flash"
  confidence_threshold: 0.7
  timeout: 5.0
```

或使用环境变量：

```bash
export XENON_INTENT_CLASSIFIER_ENABLED=true
export XENON_INTENT_CLASSIFIER_MODEL="deepseek/deepseek-v4-flash"
```

### 无需修改代码

LLM 分类器已自动集成到 `DifficultyEstimator` 中，用户无需修改任何代码，只需配置即可生效。
