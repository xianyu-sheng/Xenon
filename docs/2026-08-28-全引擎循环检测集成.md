# 全引擎循环检测集成 v0.9.1

## 📋 概述

**日期**: 2026-08-28  
**版本**: v0.9.1  
**任务**: 为 Xenon 的所有7个推理引擎集成循环检测器

继 v0.9.0 为 ReAct 引擎集成循环检测器后，本次将相同的循环检测能力扩展到所有其他引擎，解决用户报告的"一直出错一直出错"问题。

---

## 🎯 问题分析

### 7个引擎的循环风险评估

| 引擎 | 风险等级 | 循环场景 |
|------|---------|---------|
| **direct** | ✅ 无风险 | 无循环，直接对话 |
| **react** | ✅ 已解决 | v0.9.0 已集成 |
| **plan-execute** | ⚠️⚠️⚠️ 高 | 工具补救循环、验证循环、迷你ReAct循环 |
| **reflection** | ⚠️⚠️ 中 | 执行-审查循环、越改越差循环 |
| **plan-react** | ⚠️⚠️⚠️ 高 | 继承 plan-execute + react 风险 |
| **plan-reflection** | ⚠️⚠️⚠️ 高 | 继承 plan-execute + reflection 风险 |
| **react-reflection** | ⚠️⚠️⚠️ 高 | 继承 react + reflection 风险 |

### 风险场景详解

#### Plan-Execute 引擎
```python
# 场景1: 工具步骤补救循环
for attempt in range(1, self.tool_remediation_attempts + 1):
    # 如果每次都失败相同错误 → 死循环

# 场景2: 验证循环
while self.verification_loop.should_continue:
    # 反复修复→测试失败→修复 → 无进展死循环

# 场景3: 迷你ReAct循环
for rnd in range(1, self.max_mini_react_rounds + 1):
    # 可能反复调用相同工具失败
```

#### Reflection 引擎
```python
# 场景1: 执行-审查循环
for round_num in range(1, self.max_rounds + 1):
    output = self._execute(user_input, feedback, ctx)
    review = self._review(user_input, output)
    # 如果 output 每轮都一样呢？

# 场景2: 反馈无效循环
# LLM 不理解 reviewer 的反馈，反复生成相同输出
```

## 🛠️ 实施方案

### 方案选择：统一循环检测器（方案A）

**优势**：
- 代码复用性好
- 配置灵活，易于调优
- 与现有 ReAct 集成保持一致

**配置策略**：
```python
# ReAct: 已调优（v0.9.0）
REACT = {
    'window_size': 5,
    'similarity_threshold': 0.85,
    'confidence_threshold': 0.9,
    'query_confidence_threshold': 0.95
}

# Plan-Execute: 关注步骤级重复
PLAN_EXECUTE = {
    'window_size': 3,          # 更短窗口（步骤少）
    'similarity_threshold': 0.80,  # 更宽松（每步输出差异大）
}

# Reflection: 关注输出收敛
REFLECTION = {
    'window_size': 3,
    'similarity_threshold': 0.90,  # 更严格（同任务输出应相似）
}

# 组合引擎: 中等配置
COMBINED = {
    'window_size': 4-5,
    'similarity_threshold': 0.85,
}
```

## 🔄 循环检测工作流程

### Plan-Execute 引擎
```
步骤1 → 记录输出 → 检测循环？
  ├─ 否 → 继续步骤2
  ├─ 是(0.7-0.9) → 注入提示 → 继续步骤2
  └─ 是(≥0.9) → 终止执行 → 返回已完成步骤
```

### Reflection 引擎
```
轮次1 → 执行 → 审查 → 记录 → 检测循环？
  ├─ 通过 → 返回结果
  ├─ 未通过 + 无循环 → 轮次2
  ├─ 未通过 + 循环(0.7-0.9) → 注入提示 → 轮次2
  └─ 未通过 + 循环(≥0.9) → 返回最佳版本
```

### 组合引擎
```
子引擎1 → 子引擎2 → 组合层检测？
  ├─ 否 → 正常完成
  └─ 是(≥0.85/0.9) → 提前终止 → 返回当前结果
```

## 📈 性能影响

### 计算开销
- **哈希计算**: 每轮 O(n)，n 为输出长度
- **相似度比较**: 每轮 O(w)，w 为窗口大小
- **总开销**: 可忽略不计（<1ms/轮）

### 内存开销
- **ReAct**: ~5个轮次历史
- **Plan-Execute**: ~3个步骤历史
- **Reflection**: ~3个轮次历史
- **组合引擎**: ~4-5个记录

总计：每个引擎 < 50KB
