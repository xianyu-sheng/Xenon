/tools
  可用工具类型:

    command — 执行终端命令
      参数: action='dir'

    write_file — 写入文件
      参数: file_path, content

    read_file — 读取文件
      参数: file_path

    edit_file — 精确编辑文件（查找替换）
      参数: file_path, old_text, new_text

    create_directory — 创建目录
      参数: file_path

    list_files — 目录遍历（glob 模式）
      参数: file_path, pattern, max_depth

    search_files — 文件内容搜索
      参数: file_path, search_pattern, file_filter

    git — Git 操作
      参数: git_command='status|diff|log|add|commit'

    web_fetch — 抓取网页内容
      参数: url

    docs_fetch — llms.txt 优先的官方文档检索
      参数: url, query, max_pages, max_chars

    batch_write — 批量写入多个文件
      参数: files=[{path, content}, ...]

    batch_edit — 批量编辑多个文件
      参数: edits=[{file_path, old_text, new_text}, ...]

    code_index — 代码符号搜索（AST 索引）
      参数: search_pattern, file_path

    ast_analyze — Python 代码结构分析
      参数: file_path

    refactor — 重构：重命名/清理导入/分析
      参数: refactor_action, old_name, new_name

    diff_preview — 预览文件修改 diff
      参数: file_path, old_text, new_text

    mcp_call — 调用 MCP 外部工具
      参数: tool_name, tool_args

    github_fetch — GitHub 仓库操作（列出文件/获取内容/README）
      参数: repo, github_action, github_path, branch

    clone_repo — 克隆 GitHub 仓库到本地并分析代码结构
      参数: repo, branch

    lsp_goto_def — 跳转到 Python 符号定义（跨文件）
      参数: file_path, line, column

    lsp_find_refs — 查找 Python 符号的所有引用
      参数: file_path, line, column

    lsp_hover — 获取 Python 符号的类型和文档
      参数: file_path, line, column

    lsp_diagnostics — 检查 Python 文件语法错误
      参数: file_path

    lsp_symbols — 列出 Python 文件所有符号
      参数: file_path

  工具可在 YAML 工作流中通过 action_type 字段使用。
