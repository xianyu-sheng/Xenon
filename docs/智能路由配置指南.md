# 智能路由配置指南

智能路由可以根据任务特征自动选择最合适的推理范式。你有多种方式启用它：

## 方式 1: 配置文件（推荐，永久生效）

创建或编辑 `~/.xenon/config.yaml`：

```yaml
auto_route:
  enabled: true                          # 默认启用智能路由
  confidence_threshold: 0.6              # 置信度阈值（可选）
  notify_user: true                      # 是否显示切换通知（可选）
  switch_only_on_improvement: true       # 防止降级（可选）
```

**优点**：
- ✅ 永久生效，每次启动 `xenon` 都自动启用
- ✅ 可以自定义参数
- ✅ 团队协作时可以统一配置

**使用**：
```bash
xenon  # 自动启用智能路由
```

---

## 方式 2: 环境变量（临时生效）

在终端中设置环境变量：

```bash
# 临时启用（当前会话）
export XENON_AUTO_ROUTE=1
xenon

# 或一次性使用
XENON_AUTO_ROUTE=1 xenon
```

**优点**：
- ✅ 无需修改配置文件
- ✅ 适合临时测试
- ✅ 可以在脚本中使用

**使用**：
```bash
# 添加到 ~/.bashrc 或 ~/.zshrc 永久生效
echo 'export XENON_AUTO_ROUTE=1' >> ~/.bashrc
```

---

## 方式 3: CLI 参数（一次性）

启动时传递参数：

```bash
xenon --auto-route
```

**优点**：
- ✅ 最灵活，按需使用
- ✅ 不影响其他会话
- ✅ 适合偶尔使用

---

## 方式 4: REPL 命令（动态切换）

在 REPL 中随时启用/禁用：

```bash
xenon
> /auto-route on      # 启用
> /auto-route         # 查看状态
> /auto-route off     # 禁用
```

**优点**：
- ✅ 运行时动态控制
- ✅ 可以查看统计信息
- ✅ 适合调试和测试

---

## 优先级

如果多个方式同时设置，优先级为：

```
CLI 参数 > 环境变量 > 配置文件 > 默认关闭
```

示例：
```bash
# 即使配置文件设置 enabled: true
# 使用 CLI 参数也可以覆盖
xenon  # 使用配置文件的设置

# 环境变量可以覆盖配置文件
XENON_AUTO_ROUTE=0 xenon  # 禁用（即使配置文件启用）
```

## 推荐配置

### 日常开发者
```yaml
# ~/.xenon/config.yaml
auto_route:
  enabled: true
  confidence_threshold: 0.6
  notify_user: true
```

### 高级用户（想要完全控制）
```yaml
# ~/.xenon/config.yaml
auto_route:
  enabled: false  # 默认关闭，按需使用 --auto-route
```

### CI/CD 环境
```bash
# 环境变量方式
export XENON_AUTO_ROUTE=1
export XENON_AUTO_ROUTE_CONFIDENCE=0.7  # 更保守的阈值
```

## 故障排查

### 问题：配置文件不生效

1. 检查文件路径是否正确：`~/.xenon/config.yaml`
2. 检查 YAML 语法是否正确
3. 检查文件权限
4. 查看启动日志是否有错误

### 问题：环境变量不生效

1. 检查变量是否正确导出：`echo $XENON_AUTO_ROUTE`
2. 确保在启动 xenon 的同一个终端会话中设置
3. 检查拼写是否正确（区分大小写）

### 问题：智能路由没有切换范式

1. 检查置信度是否低于阈值
2. 检查当前范式是否已经是推荐的范式
3. 使用 `/auto-route` 查看统计信息
4. 查看是否有防降级保护触发

## 示例场景

### 场景 1: 我想每次都自动启用

```bash
# 创建配置文件
cat > ~/.xenon/config.yaml << EOF
auto_route:
  enabled: true
EOF

# 以后每次启动都自动启用
xenon
```

### 场景 2: 我想默认关闭，偶尔使用

```bash
# 不创建配置文件，或设置 enabled: false
# 需要时使用 CLI 参数
xenon --auto-route
```

### 场景 3: 我想在特定项目中启用

```bash
# 在项目目录创建 .envrc（使用 direnv）
echo 'export XENON_AUTO_ROUTE=1' > .envrc
direnv allow

# 进入项目目录时自动启用
cd myproject
xenon  # 自动启用智能路由
```
