## 🎯 核心功能特性

### 1. 智能分级检测

| 置信度 | 动作 | 适用场景 |
|--------|------|---------|
| **≥0.9** | 立即终止 | Plan-Execute, Plan-React |
| **≥0.85** | 立即终止 | Reflection 组合引擎 |
| **0.7-0.9** | 注入提示 | 所有引擎 |
| **<0.7** | 继续执行 | 所有引擎 |

### 2. 引擎特化配置

**Plan-Execute (window=3, threshold=0.80)**
- 步骤数少，使用短窗口
- 每步输出差异大，使用宽松阈值
- 适合检测工具补救循环、验证循环

**Reflection (window=3, threshold=0.90)**
- 轮数少，使用短窗口
- 同任务输出应收敛，使用严格阈值
- 适合检测执行-审查循环

**组合引擎 (window=4-5, threshold=0.85)**
- 步骤数多，使用较长窗口
- 平衡配置，适合多层嵌套循环检测

### 3. 多维度检测

- ✅ **输出哈希相似度** - 检测完全相同的输出
- ✅ **工具调用模式** - 检测重复的工具调用序列
- ✅ **错误消息重复** - 检测相同的错误反复出现
- ✅ **思考内容相似度** - 检测 LLM 思考过程的重复

## 📈 性能影响

### 计算开销
- **哈希计算**: <0.5ms/轮
- **相似度比较**: <0.5ms/轮
- **总开销**: <1ms/轮（可忽略不计）

### 内存开销
- **ReAct**: ~5个轮次 × 1KB = 5KB
- **Plan-Execute**: ~3个步骤 × 1KB = 3KB
- **Reflection**: ~3个轮次 × 1KB = 3KB
- **组合引擎**: ~4-5个记录 × 1KB = 4-5KB

**总计**: 每个引擎 <10KB（可忽略不计）

### Token 节省
假设循环平均在第6轮被检测到，每轮平均1000 tokens：
- **无检测**: 继续到 max_iterations (40轮) = 40,000 tokens
- **有检测**: 终止于第6轮 = 6,000 tokens
- **节省**: 34,000 tokens/次 (~85% 节省)

## 🔧 技术实现细节

### 初始化模式
```python
# 每个引擎在 __init__ 中初始化
self._loop_detector = LoopDetector(
    window_size=3,              # 根据引擎特点调整
    similarity_threshold=0.80,  # 根据引擎特点调整
    enabled=True,
)
```

### 重置模式
```python
# 每次 run() 开始时重置
def run(self, user_input, context=None, ctx_mgr=None):
    self._loop_detector.reset()
    # ... 引擎逻辑
```

### 检测模式
```python
# 每轮/步骤后检测
self._loop_detector.add_turn(output, tool_calls, error, thought)
loop_result = self._loop_detector.check()

if loop_result.is_loop:
    if loop_result.confidence >= 0.9:
        # 高置信度：立即终止
        logger.warning("检测到循环，终止执行")
        break
    elif loop_result.confidence >= 0.7:
        # 中等置信度：注入提示
        hint = f"⚠️ 循环检测提示: {loop_result.reason}"
        # 注入到下一轮
```
